Workflow Overview

How Smart Insurance Prediction Works

The popup reflects the actual backend flow of Smart Insurance Advisor, from user input and Flask validation to `model.pkl` prediction, risk scoring, and the final result shown on the predictor page.

1

User details are collected

The predictor form captures age, BMI, gender, smoker status, alcohol usage, number of dependents, and other profile details needed for premium estimation.

2

Flask validates the request

The backend validates submitted values before prediction, ensuring the request contains complete, correctly formatted, and safe input data.

3

`model.pkl` processes the input

Validated user data is transformed into the format expected by the trained machine learning model stored in `model.pkl`.

4

Insurance premium is predicted

The model analyzes the health and lifestyle features and returns an estimated insurance premium for that user profile.

5

Risk score and category are generated

The application derives a risk score and maps it into a Low, Medium, or High category so the prediction is easier to understand.

6

Results appear on the predictor page

The final prediction, risk score, and category are displayed back on the predictor page so the user can review the outcome immediately.
