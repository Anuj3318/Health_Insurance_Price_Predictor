# 🏥 Health Insurance Price Predictor

A **machine learning-based web application** that predicts health insurance prices based on user-specific health and demographic information. The project combines **Python, Flask, Machine Learning, HTML, CSS, JavaScript, and MySQL** to provide an interactive platform for estimating insurance costs.

## 🚀 Project Overview

The Health Insurance Price Predictor allows users to enter details such as **age, gender, BMI, number of dependents, smoking habits, and alcohol consumption** to estimate their health insurance premium.

The prediction model is built using **Linear Regression** and trained on a structured CSV dataset. The Flask backend handles user authentication, prediction requests, data processing, and communication between the machine learning model and the web interface.

## ✨ Key Features

* 🔐 User **Login & Signup** functionality
* 📱 OTP-based user verification
* 🧮 Health insurance price prediction using **Linear Regression**
* 👤 User profile management
* 📊 Prediction history through a personalized dashboard
* 🏦 Comparison of different insurance plans
* 🎟️ Coupon and discount functionality
* 💳 Simulated insurance plan purchase and checkout
* 📋 Purchased plan details and claim-filing section
* 📱 Responsive and user-friendly web interface
* 💾 Database integration for storing user and application data

## 🧠 Machine Learning

The application uses a **Linear Regression model** to estimate insurance prices from user-provided health and demographic attributes.

The general workflow is:

**User Input → Data Preprocessing → ML Model → Predicted Insurance Price → Web Interface**
